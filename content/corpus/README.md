# Research notes for the AI

Every `.md` file in this folder (except this one) is added to what the chatbot and summarizer may use.
Write notes **in the group's own words**, one topic per file, e.g. `dartmouth-proposal.md`.

Optional first lines (then a blank line):

```
era: era-1
sources: mccarthy-1955, another-source-id

# The Dartmouth proposal

Your notes here...
```

`era` is `era-1`, `era-2` or `era-3`. `sources` are ids from `content/sources.ts`.
The chatbot cites these notes, so keep facts accurate and sourced. Do not paste whole copyrighted articles.
